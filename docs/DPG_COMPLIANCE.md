# DPG alignment and evidence

Beebo is designed toward the [Digital Public Goods Standard](https://www.digitalpublicgoods.net/standard), which covers nine indicators, including three do-no-harm subareas. It has not been reviewed or recognized by the Digital Public Goods Alliance. This matrix is a working evidence index, not certification.

| Area                                | Current evidence                                                                                        | Remaining work                                                                                                 |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| SDG relevance                       | README mission; tutoring/small-group scope; two learning activities; portability and bandwidth settings | Educator trials and evidence of usefulness, inclusion, and constrained-network operation                       |
| Open licensing                      | Apache-2.0 LICENSE; dependency gate, notices, and SBOM                                                  | Release-platform artifact reviews and ongoing dependency monitoring                                            |
| Clear ownership                     | Repository steward and contributor copyright policy in GOVERNANCE                                       | Confirm formal ownership/stewardship and decision responsibilities                                             |
| Platform independence               | Browser client, self-hostable signaling, operator-controlled TURN; no mandatory cloud/account service   | Document tested browser/platform matrix and reproducible deployments                                           |
| Documentation                       | README, contribution/workflow, architecture, deployment, review, privacy, and security documents        | Operator validation and educator-facing guides                                                                 |
| Data extraction                     | Versioned JSON export/import; PNG view export; no proprietary backend dependency                        | Format migration policy and compatibility fixtures across releases                                             |
| Privacy and applicable requirements | Data-flow/retention inventory; no telemetry; opt-in local saving                                        | Jurisdiction/use-specific assessment, contacts, and deployment notices                                         |
| Standards and best practices        | WebRTC, WebSocket, JSON, Web Crypto; accessibility target; test and license gates                       | Independent accessibility/security assessment and operational hardening                                        |
| Data privacy/security               | Application encryption, scoped signaling, quotas, validation, relay-only default                        | Threat-model review, key lifecycle, recovery/refresh, adversarial and live-TURN tests                          |
| Inappropriate/illegal content       | Invitation-only trusted groups; no public directory or content hosting                                  | Operator procedures, reporting/removal design, and enforceable access controls                                 |
| Harassment protection               | Contribution conduct policy; private invitation capability                                              | Publish monitored conduct contact; teacher roles, participant removal, key rotation, and abuse-response trials |

Open source does not imply that learner content must be open data. Do not publish board contents, real invitations, or learner identities as evidence. Use synthetic examples and privacy-preserving measurements.

DPG nomination should follow resolution of the evidence gaps and review of the then-current standard. Local adoption and legal responsibilities still require assessment by each operator.
